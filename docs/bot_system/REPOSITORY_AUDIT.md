# Repository audit — Human Poker

Inspected 9 November 2026. This is a backend foundation integrated with the existing TypeScript rules, not a replacement poker engine or a completed production bot.

## Safe reuse and remaining gaps

Reuse the rules, options, showdown evaluator, chart format and existing test runner. New `src/bot_engine/` separates the information boundary, identity, beliefs, ranges, policy and simulation. Existing production bot selection is unchanged while the new policy is evaluated.

Missing: certified postflop data adapter; calibrated action likelihoods and range priors; position/board-aware human policies; full profile parameter families; global identity and lifetime-belief coordination across table objects; safe live-worker activation; production event derivation and delivery; temporary-state modelling; generation calibration/rejection; large paired performance experiments and human studies. The full-hand harness supports 2–9 seats and a heads-up paired-deal population suite; neither establishes multiplayer strategic quality. A 32-context synthetic calibration/rejection battery now measures conditional policy diversity, not human representativeness.
